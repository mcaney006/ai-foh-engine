# Safety

This process is allowed to recommend. It is not allowed to be loud, howly,
or fast.

1. Locked names: `talkback`, `announce`. Extend the list in `SafetyGate`.
2. No live socket is opened by `foh-engine`. OSC is encoded and printed.
3. Accept from verify is required before a command is even journaled.
4. EQ and dynamics stay on the offline strip until a public desk mapping
   exists. Shipping a guess OSC path for Mustard EQ would be a show killer
   dressed as a feature.

If you add a send path: keep the journal, keep the gate, keep verify, and
add a human enable flag that defaults off.
